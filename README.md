## English

h2v provides a private admin UI for a small self-hosted VPN node:

- user management with traffic limits and expiration dates;
- automatic Xray and Hysteria 2 config rendering;
- VLESS Reality and Hysteria 2 subscription links;
- QR codes and public subscription portal pages;
- traffic accounting and retention;
- Telemt-based Telegram Proxy add-on service;
- PostgreSQL backups and restore helpers;
- geodata updates for routing and ACL rules;
- systemd units for production operation.

### Quick Install

For production, install a released tag instead of a moving branch. Replace `v0.1.1` with the latest release tag:

```bash
export H2V_REF=v0.1.1
bash <(curl -fsSL "https://raw.githubusercontent.com/ProstyGospody/h2v/${H2V_REF}/install.sh")
```

For development or testing the current `main` branch:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ProstyGospody/h2v/main/install.sh)
```

Run the installer on a fresh Ubuntu server as `root`. It asks for:

- panel domain, for example `vpn.example.com`;
- public panel HTTPS port;
- VLESS Reality TCP port;
- Hysteria 2 UDP port;
- admin username and password.

If `/opt/mypanel/.env` already exists during update, the installer asks whether to keep the current configuration or reconfigure domain and public ports.

### Requirements

| Requirement | Notes |
| --- | --- |
| OS | Ubuntu 22.04 or 24.04 with systemd |
| Access | Root shell or root user |
| Domain | A real DNS name pointed to the server |
| Panel | TCP `443` or `PANEL_PUBLIC_PORT` |
| VLESS | TCP `VLESS_PORT`, default `8444` |
| Hysteria 2 | UDP `HY2_PORT`, default `8443` |
| Telegram Proxy | TCP `TELEGRAM_PROXY_PORT`, default `9443` |
| ACME | TCP `80` for Let's Encrypt HTTP-01 validation |

### Runtime Layout

All runtime files live under `/opt/mypanel`.

| Path | Purpose |
| --- | --- |
| `/opt/mypanel/.env` | Runtime configuration and secrets |
| `/opt/mypanel/bin/panel` | Backend binary |
| `/opt/mypanel/bin/telemt` | Telegram Proxy binary |
| `/opt/mypanel/frontend` | Built React frontend |
| `/opt/mypanel/templates` | Runtime config templates |
| `/opt/mypanel/configs` | Rendered Xray, Hysteria 2, and Telemt configs |
| `/opt/mypanel/data/backups` | Database backups |
| `/opt/mypanel/data/geodata` | `geoip.dat` and `geosite.dat` |

### Daily Commands

```bash
sudo /opt/mypanel/install.sh update
sudo /opt/mypanel/install.sh geodata
sudo /opt/mypanel/install.sh reset-admin
sudo /opt/mypanel/install.sh backup
sudo /opt/mypanel/install.sh restore /opt/mypanel/data/backups/panel-YYYY-MM-DD-HHMMSS.sql.gz
sudo /opt/mypanel/install.sh uninstall
```

### Important Configuration

Runtime configuration is stored in `/opt/mypanel/.env`.

Production values to protect:

- `PANEL_JWT_SECRET`: random value, at least 32 characters;
- `DB_PASSWORD`: PostgreSQL password;
- `REALITY_PRIVATE_KEY` and `REALITY_PUBLIC_KEY`: generated by `xray x25519`;
- `HY2_TRAFFIC_SECRET`: local Hysteria stats/auth secret;
- `HY2_OBFS_PASSWORD`: required when `HY2_OBFS_ENABLED=true`;
- `TELEGRAM_PROXY_SECRET`: Telegram proxy base secret generated by the installer;
- `TELEGRAM_PROXY_MASK_DOMAIN`: SNI/mask domain used in the `ee...` Telegram link.

`PANEL_ALLOW_INSECURE_DEFAULTS=true` is only for local development.

Optional stability knobs:

- `PANEL_ARGON2_MAX_PARALLEL`: concurrent password hashes, default `2`;
- `PANEL_COLLECTOR_INTERVAL`: traffic collector cadence, default `10s`;
- `PANEL_ENFORCER_INTERVAL`: limit/expiry enforcement cadence, default `30s`;
- `PANEL_CORE_RECONCILE_INTERVAL`: core config reconcile cadence, default `60s`;
- `PANEL_CACHE_REFRESH_INTERVAL`: Hysteria auth cache refresh cadence, default `5m`.

### Advanced Install

| Variable | Purpose |
| --- | --- |
| `H2V_REF=v0.1.1` | Install a specific tag, branch, or commit |
| `H2V_SOURCE_SHA256=<sha256>` | Verify the downloaded source archive |
| `H2V_REQUIRE_SOURCE_SHA256=1` | Fail if a source checksum is not provided |
| `TELEMT_VERSION=3.4.3` | Pin the Telemt release used by Telegram Proxy |
| `H2V_NODE_MAX_OLD_SPACE_MB=512` | Cap Node.js heap during frontend build; set `0` to disable |

### Troubleshooting

Panel logs:

```bash
journalctl -u panel.service -n 100 --no-pager
```

Core logs:

```bash
journalctl -u xray.service -n 80 --no-pager
journalctl -u hysteria.service -n 80 --no-pager
journalctl -u h2v-telegram.service -n 80 --no-pager
```

Restart services:

```bash
sudo systemctl restart panel.service
sudo systemctl restart xray.service hysteria.service h2v-telegram.service
```

Check memory:

```bash
systemctl show panel.service xray.service hysteria.service h2v-telegram.service -p MemoryCurrent -p MemoryPeak
systemd-cgtop
```

## Русский

h2v - это панель для собственного VPN-сервера. Она устанавливает и управляет Xray VLESS Reality, Hysteria 2 и отдельным Telegram Proxy relay на базе Telemt.

Возможности:

- управление пользователями, лимитами трафика и сроками действия;
- автоматическая генерация конфигов Xray и Hysteria 2;
- ссылки подписки для VLESS Reality и Hysteria 2;
- QR-коды и публичная страница подписки пользователя;
- учет трафика;
- отдельный Telegram Proxy add-on;
- резервные копии PostgreSQL;
- обновление GeoIP/Geosite данных;
- готовые systemd-сервисы для эксплуатации.

### Быстрая установка

Для production используйте релизный тег, а не плавающую ветку. Замените `v0.1.1` на актуальный тег релиза:

```bash
export H2V_REF=v0.1.1
bash <(curl -fsSL "https://raw.githubusercontent.com/ProstyGospody/h2v/${H2V_REF}/install.sh")
```

Для теста текущей ветки `main`:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ProstyGospody/h2v/main/install.sh)
```

Запускайте installer на чистом Ubuntu-сервере от `root`. Он спросит:

- домен панели, например `vpn.example.com`;
- публичный HTTPS-порт панели;
- TCP-порт VLESS Reality;
- UDP-порт Hysteria 2;
- логин и пароль администратора.

При обновлении существующей установки installer сохранит `/opt/mypanel/.env` и предложит либо оставить текущие настройки, либо заново настроить домен и публичные порты.

### Требования

| Требование | Детали |
| --- | --- |
| ОС | Ubuntu 22.04 или 24.04 с systemd |
| Доступ | root shell или root user |
| Домен | Реальный DNS A-record на сервер |
| Панель | TCP `443` или `PANEL_PUBLIC_PORT` |
| VLESS | TCP `VLESS_PORT`, по умолчанию `8444` |
| Hysteria 2 | UDP `HY2_PORT`, по умолчанию `8443` |
| Telegram Proxy | TCP `TELEGRAM_PROXY_PORT`, по умолчанию `9443` |
| ACME | TCP `80` для Let's Encrypt HTTP-01 |

| Путь | Назначение |

| `/opt/mypanel/bin/panel` | Backend binary |

### Важные настройки

Основной файл настроек: `/opt/mypanel/.env`.

Берегите эти значения:

- `PANEL_JWT_SECRET`: случайная строка не короче 32 символов;
- `DB_PASSWORD`: пароль PostgreSQL;
- `REALITY_PRIVATE_KEY` и `REALITY_PUBLIC_KEY`: ключи Xray Reality;
- `HY2_TRAFFIC_SECRET`: локальный секрет Hysteria stats/auth;
- `HY2_OBFS_PASSWORD`: обязателен при `HY2_OBFS_ENABLED=true`;
- `TELEGRAM_PROXY_SECRET`: базовый секрет Telegram Proxy;
- `TELEGRAM_PROXY_MASK_DOMAIN`: mask/SNI domain для `ee...` Telegram-ссылки.

`PANEL_ALLOW_INSECURE_DEFAULTS=true` используйте только для локальной разработки.

Настройки стабильности для маленьких VPS:

- `PANEL_ARGON2_MAX_PARALLEL`: число одновременных password hash, по умолчанию `2`;
- `PANEL_COLLECTOR_INTERVAL`: частота сбора трафика, по умолчанию `10s`;
- `PANEL_ENFORCER_INTERVAL`: частота проверки лимитов и истечения срока, по умолчанию `30s`;
- `PANEL_CORE_RECONCILE_INTERVAL`: частота сверки конфигов cores, по умолчанию `60s`;
- `PANEL_CACHE_REFRESH_INTERVAL`: частота обновления auth cache для Hysteria, по умолчанию `5m`.
