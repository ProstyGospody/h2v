<a id="english"></a>

## English

**h2v** is a private web panel for a small self-hosted VPN server. It keeps user management, subscriptions, traffic, service status, and protocol settings in one focused interface.

### At a Glance

| Users | Subscriptions | Dashboard |
| --- | --- | --- |
| Create users, set limits, disable access, and control expiration dates. | Generate subscription links, QR codes, and public user pages. | Track traffic, uptime, online state, and core service health. |

| Configuration | Backups | Routing Data |
| --- | --- | --- |
| Manage Xray VLESS Reality and Hysteria 2 settings from the panel. | Keep backup and restore actions close to the panel workflow. | Update GeoIP and Geosite data without leaving the interface. |

### Core Projects

h2v builds on these core projects:

- **Xray-core official repository:** [github.com/XTLS/Xray-core](https://github.com/XTLS/Xray-core)
- **Hysteria 2 official repository:** [github.com/apernet/hysteria](https://github.com/apernet/hysteria)

### Intended Use

h2v is designed for a fresh Ubuntu server with a real domain pointed to it. The installer prepares the panel, backend, frontend, database, services, Xray, and Hysteria 2.

## Русский

**h2v** - приватная веб-панель для небольшого VPN-сервера, который вы держите у себя. В одном интерфейсе собраны пользователи, подписки, трафик, состояние сервисов и настройки протоколов.

### Кратко

| Пользователи | Подписки | Дашборд |
| --- | --- | --- |
| Создание пользователей, лимиты, отключение доступа и сроки действия. | Ссылки подписки, QR-коды и публичные страницы пользователей. | Трафик, uptime, online-статус и состояние основных сервисов. |

| Конфигурация | Резервные копии | Геоданные |
| --- | --- | --- |
| Настройки Xray VLESS Reality и Hysteria 2 прямо из панели. | Резервное копирование и восстановление рядом с рабочим процессом панели. | Обновление GeoIP и Geosite без ручного перехода на сервер. |

### Основные Проекты

h2v опирается на эти основные проекты:

- **Официальный репозиторий Xray-core:** [github.com/XTLS/Xray-core](https://github.com/XTLS/Xray-core)
- **Официальный репозиторий Hysteria 2:** [github.com/apernet/hysteria](https://github.com/apernet/hysteria)

### Для Чего

h2v рассчитан на чистый Ubuntu-сервер с реальным доменом, направленным на него. Установщик подготавливает панель, серверную часть, веб-интерфейс, базу данных, сервисы, Xray и Hysteria 2.
