# h2v

h2v is a self-hosted VPN panel for Xray VLESS Reality, Hysteria 2, and a
dedicated Telegram MTProxy-compatible relay.

It gives you a private admin UI, user management, traffic accounting, automatic
core config rendering, subscription links, QR codes, backups, geodata updates,
and ready-to-use systemd services.

## Quick Install

Run this on a fresh Ubuntu server as `root`:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ProstyGospody/h2v/main/install.sh)
```

The installer is interactive. It will ask for:

- panel domain, for example `vpn.example.com`
- public panel HTTPS port
- VLESS Reality TCP port
- Hysteria 2 UDP port
- admin username and password

The installer also generates a Telegram proxy secret. The ready
`https://t.me/proxy?...` link lives on the Telegram page, separate from users
and subscription QR codes.

On updates, if `/opt/mypanel/.env` already exists, the installer asks whether to
keep the current config or reconfigure it with a simple `1 / 2` choice.

## Requirements

| Requirement | Notes |
| --- | --- |
| OS | Ubuntu 22.04 or 24.04 with systemd |
| Access | Root shell or root user |
| Domain | A real DNS name pointed to the server |
| Panel | TCP `443` or `PANEL_PUBLIC_PORT` |
| VLESS | TCP `VLESS_PORT`, default `8444` |
| Hysteria 2 | UDP `HY2_PORT`, default `8443` |
| Telegram Proxy | TCP `TELEGRAM_PROXY_PORT`, default `9443` |
| ACME | TCP `80` for Let's Encrypt HTTP-01 validation |

## What Gets Installed

- Go backend service: `panel.service`
- React admin frontend served by the panel
- PostgreSQL database and migrations
- Xray-core with VLESS Reality
- Hysteria 2 server
- h2v Telegram Proxy service: `h2v-telegram.service`
- Caddy reverse proxy with automatic TLS
- Geodata updater: `h2v-geodata-update.timer`
- Backup and restore helpers

All runtime files live under `/opt/mypanel`.

## Daily Commands

```bash
sudo /opt/mypanel/install.sh update
sudo /opt/mypanel/install.sh geodata
sudo /opt/mypanel/install.sh reset-admin
sudo /opt/mypanel/install.sh backup
sudo /opt/mypanel/install.sh restore /opt/mypanel/data/backups/panel-YYYY-MM-DD-HHMMSS.sql.gz
sudo /opt/mypanel/install.sh uninstall
```

## Configuration

Runtime configuration is stored in:

```text
/opt/mypanel/.env
```

Important production values:

- `PANEL_JWT_SECRET`: random value, at least 32 characters
- `DB_PASSWORD`: PostgreSQL password
- `REALITY_PRIVATE_KEY` and `REALITY_PUBLIC_KEY`: generated by `xray x25519`
- `HY2_TRAFFIC_SECRET`: local Hysteria stats/auth secret
- `HY2_OBFS_PASSWORD`: required when `HY2_OBFS_ENABLED=true`
- `TELEGRAM_PROXY_SECRET`: Telegram proxy base secret generated by the installer
- `TELEGRAM_PROXY_MASK_DOMAIN`: SNI/mask domain used in the `ee...` link

`PANEL_ALLOW_INSECURE_DEFAULTS=true` is only for local development.

## Backups

Database backups are stored in `BACKUP_DIR`, default:

```text
/opt/mypanel/data/backups
```

Backups are retained for `BACKUP_RETENTION_DAYS`.
Raw traffic samples in `traffic_log` are retained for `TRAFFIC_RETENTION_DAYS`.

API backup exports include user subscription secrets. Treat them as sensitive.

## Security Notes

h2v assumes the panel backend listens on loopback and is published only through
the installer-managed Caddy site. Do not expose `/metrics` or `/hy2/auth`
through another public reverse proxy.

Admin API access uses a short-lived bearer token plus an HTTP-only refresh
cookie. Subscription URLs are bearer credentials for users; rotate them if they
leak.

## Troubleshooting

Panel logs:

```bash
journalctl -u panel.service -n 100 --no-pager
```

Core logs:

```bash
journalctl -u xray.service -n 80 --no-pager
journalctl -u hysteria.service -n 80 --no-pager
journalctl -u h2v-telegram.service -n 80 --no-pager
```

Telegram Proxy unavailable from outside:

```bash
sudo ss -ltnp | grep ':9443'
sudo ufw allow 9443/tcp
journalctl -u h2v-telegram.service -n 80 --no-pager
```

Also check the VPS/cloud firewall and keep the Telegram DNS record in DNS-only
mode if it is hosted on Cloudflare.

Restart services:

```bash
sudo systemctl restart panel.service
sudo systemctl restart xray.service hysteria.service h2v-telegram.service
```

Reset admin password:

```bash
sudo /opt/mypanel/install.sh reset-admin
```

## Advanced Install

For production pinning or source verification, prepend environment variables to
the same install command shown above.

| Variable | Purpose |
| --- | --- |
| `H2V_REF=v0.1.1` | Install a specific tag, branch, or commit |
| `H2V_SOURCE_SHA256=<sha256>` | Verify the downloaded source archive |
| `H2V_REQUIRE_SOURCE_SHA256=1` | Fail if a source checksum is not provided |
