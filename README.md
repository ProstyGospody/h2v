## English

h2v provides a private admin UI for a small self-hosted VPN node:

- user management with traffic limits and expiration dates;
- automatic Xray and Hysteria 2 config rendering;
- VLESS Reality and Hysteria 2 subscription links;
- QR codes and public subscription portal pages;
- traffic accounting and retention;
- PostgreSQL backups and restore helpers;
- geodata updates for routing and ACL rules;
- systemd units for production operation.

### Quick Install

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ProstyGospody/h2v/main/install.sh)
```

Run the installer on a fresh Ubuntu server as `root`. It asks for:

- h2v domain, for example `vpn.example.com`;
- public h2v HTTPS port;
- VLESS Reality TCP port;
- Hysteria 2 UDP port;
- admin username and password.

If `/opt/h2v/.env` already exists during update, the installer asks whether to keep the current configuration or reconfigure domain and public ports.

### Requirements

| Requirement | Notes |
| --- | --- |
| OS | Ubuntu 22.04 or 24.04 with systemd |
| Access | Root shell or root user |
| Domain | A real DNS name pointed to the server |
| h2v | TCP `443` or `H2V_PUBLIC_PORT` |
| VLESS | TCP `VLESS_PORT`, default `8444` |
| Hysteria 2 | UDP `HY2_PORT`, default `8443` |
| ACME | TCP `80` for Let's Encrypt HTTP-01 validation |

### Runtime Layout

All runtime files live under `/opt/h2v`.

| Path | Purpose |
| --- | --- |
| `/opt/h2v/.env` | Runtime configuration and secrets |
| `/opt/h2v/bin/h2v` | Backend binary |
| `/opt/h2v/frontend` | Built React frontend |
| `/opt/h2v/templates` | Runtime config templates |
| `/opt/h2v/configs` | Rendered Xray and Hysteria 2 configs |
| `/opt/h2v/data/backups` | Database backups |
| `/opt/h2v/data/geodata` | `geoip.dat` and `geosite.dat` |

### Daily Commands

```bash
sudo /opt/h2v/install.sh update
sudo /opt/h2v/install.sh geodata
sudo /opt/h2v/install.sh reset-admin
sudo /opt/h2v/install.sh backup
sudo /opt/h2v/install.sh restore /opt/h2v/data/backups/h2v-YYYY-MM-DD-HHMMSS.sql.gz
sudo /opt/h2v/install.sh uninstall
```

### Important Configuration

Runtime configuration is stored in `/opt/h2v/.env`.

Production values to protect:

- `H2V_JWT_SECRET`: random value, at least 32 characters;
- `DB_PASSWORD`: PostgreSQL password;
- `REALITY_PRIVATE_KEY` and `REALITY_PUBLIC_KEY`: generated by `xray x25519`;
- `HY2_TRAFFIC_SECRET`: local Hysteria stats/auth secret;
- `HY2_OBFS_PASSWORD`: required when `HY2_OBFS_ENABLED=true`.

`H2V_ALLOW_INSECURE_DEFAULTS=true` is only for local development.

Optional stability knobs:

- `PUBLIC_SERVER_IP`: direct IP endpoint used in generated protocol links; the installer auto-detects it when empty;
- `H2V_ARGON2_MAX_PARALLEL`: concurrent password hashes, default `2`; installer may set `1` on sub-1 GiB hosts;
- `H2V_COLLECTOR_INTERVAL`: traffic collector cadence, default `10s`;
- `H2V_ENFORCER_INTERVAL`: limit/expiry enforcement cadence, default `30s`;
- `H2V_CORE_RECONCILE_INTERVAL`: core config reconcile cadence, default `60s`;
- `H2V_CACHE_REFRESH_INTERVAL`: Hysteria auth cache refresh cadence, default `5m`.

### Advanced Install

| Variable | Purpose |
| --- | --- |
| `H2V_REF=v0.1.1` | Install a specific tag, branch, or commit |
| `H2V_SOURCE_SHA256=<sha256>` | Verify the downloaded source archive |
| `H2V_REQUIRE_SOURCE_SHA256=1` | Fail if a source checksum is not provided |
| `H2V_NODE_MAX_OLD_SPACE_MB=512` | Cap Node.js heap during frontend build; set `0` to disable |
| `H2V_AUTO_SWAP=0` | Disable automatic swapfile creation on low-memory hosts |
| `H2V_SWAP_FILE=/swapfile` | Swapfile path used when automatic swap is needed |
| `H2V_SWAP_SIZE_MB=2048` | Override automatic swapfile size |

## Русский

h2v - это панель для собственного VPN-сервера. Она устанавливает и управляет Xray VLESS Reality и Hysteria 2.

Возможности:

- управление пользователями, лимитами трафика и сроками действия;
- автоматическая генерация конфигов Xray и Hysteria 2;
- ссылки подписки для VLESS Reality и Hysteria 2;
- QR-коды и публичная страница подписки пользователя;
- учет трафика;
- резервные копии PostgreSQL;
- обновление GeoIP/Geosite данных;
- готовые systemd-сервисы для эксплуатации.

### Быстрая установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ProstyGospody/h2v/main/install.sh)
```

Запускайте installer на чистом Ubuntu-сервере от `root`. Он спросит:

- домен панели, например `vpn.example.com`;
- публичный HTTPS-порт панели;
- TCP-порт VLESS Reality;
- UDP-порт Hysteria 2;
- логин и пароль администратора.

При обновлении существующей установки installer сохранит `/opt/h2v/.env` и предложит либо оставить текущие настройки, либо заново настроить домен и публичные порты.

### Требования

| Требование | Детали |
| --- | --- |
| ОС | Ubuntu 22.04 или 24.04 с systemd |
| Доступ | root shell или root user |
| Домен | Реальный DNS A-record на сервер |
| Панель | TCP `443` или `H2V_PUBLIC_PORT` |
| VLESS | TCP `VLESS_PORT`, по умолчанию `8444` |
| Hysteria 2 | UDP `HY2_PORT`, по умолчанию `8443` |
| ACME | TCP `80` для Let's Encrypt HTTP-01 |

### Где лежат файлы

Все runtime-файлы находятся в `/opt/h2v`.

| Путь | Назначение |
| --- | --- |
| `/opt/h2v/.env` | Настройки и секреты |
| `/opt/h2v/bin/h2v` | Backend binary |
| `/opt/h2v/frontend` | Собранный frontend |
| `/opt/h2v/templates` | Шаблоны runtime-конфигов |
| `/opt/h2v/configs` | Сгенерированные конфиги Xray и Hysteria 2 |
| `/opt/h2v/data/backups` | Резервные копии базы |
| `/opt/h2v/data/geodata` | `geoip.dat` и `geosite.dat` |

### Важные настройки

Основной файл настроек: `/opt/h2v/.env`.

Берегите эти значения:

- `H2V_JWT_SECRET`: случайная строка не короче 32 символов;
- `DB_PASSWORD`: пароль PostgreSQL;
- `REALITY_PRIVATE_KEY` и `REALITY_PUBLIC_KEY`: ключи Xray Reality;
- `HY2_TRAFFIC_SECRET`: локальный секрет Hysteria stats/auth;
- `HY2_OBFS_PASSWORD`: обязателен при `HY2_OBFS_ENABLED=true`.

`H2V_ALLOW_INSECURE_DEFAULTS=true` используйте только для локальной разработки.

Настройки стабильности для маленьких VPS:

- `H2V_ARGON2_MAX_PARALLEL`: число одновременных password hash, по умолчанию `2`;
- `H2V_COLLECTOR_INTERVAL`: частота сбора трафика, по умолчанию `10s`;
- `H2V_ENFORCER_INTERVAL`: частота проверки лимитов и истечения срока, по умолчанию `30s`;
- `H2V_CORE_RECONCILE_INTERVAL`: частота сверки конфигов cores, по умолчанию `60s`;
- `H2V_CACHE_REFRESH_INTERVAL`: частота обновления auth cache для Hysteria, по умолчанию `5m`.
